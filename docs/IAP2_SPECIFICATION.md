# iAP2 Specification & Message Catalog

This document establishes the **Single Source of Truth (SSOT)** for iAP2 (iPod Accessory Protocol v2) messages, parameters, enums, and wire layouts utilized in CarPlayStation, aligned with Apple's authoritative MFi / iAP2 specification and reference implementations (`Reference/carplayd`, `Reference/xcertplay`).

Implementation mapping: [`Core/Protocol/Iap2MessageCatalog.h`](../Core/Protocol/Iap2MessageCatalog.h) and [`Core/Protocol/Iap2MessageCatalog.cpp`](../Core/Protocol/Iap2MessageCatalog.cpp).

---

## 1. iAP2 Packet Framing & Control Session Layout

All iAP2 packets over the link session use standard framing:
```text
+--------+--------+-----------------+-------------------+-------------------+----------+-----------+
| 0xFF   | 0x5A   | Packet Len BE16 | Control Byte (u8) | Seq Number (u8)   | Ack (u8) | SessionId |
+--------+--------+-----------------+-------------------+-------------------+----------+-----------+
| Header Checksum | Payload Bytes...                                                   | Checksum  |
+-----------------+--------------------------------------------------------------------+-----------+
```

### Control Session Payload (`SessionId = 1`)
Control session messages carry an inner Apple payload header:
```text
[0x40 0x40] [Total Length BE16] [Message ID BE16] [TLV Group 0] [TLV Group 1] ...
```

### TLV Group Layout
Each parameter inside a message payload is encoded as a TLV group:
```text
[Group Length BE16] [Parameter ID BE16] [Value Bytes...]
```
*Note: `Group Length` includes the 4-byte header (`2 bytes length + 2 bytes param ID`). Therefore, an empty/presence-only param has length `4`.*

## 2. Authoritative Message ID Directory

### 2.1 Authentication Plane (`0xAA0x`)
| Message ID | Hex | Direction | Description | Implemented In |
|---|---|---|---|---|
| `RequestAuthCertificate` | `0xAA00` | Device → Accessory | iPhone requests accessory MFi certificate | `CoreIap2PacketHandler` |
| `AuthCertificate` | `0xAA01` | Accessory → Device | Accessory provides MFi certificate binary | `BuildMfiGroup` |
| `RequestAuthChallenge` | `0xAA02` | Device → Accessory | iPhone provides random challenge nonce | `ExtractChallenge` |
| `AuthResponse` | `0xAA03` | Accessory → Device | Accessory provides signature generated by MFi chip | `MfiMsgSignature` |
| `AuthFailed` | `0xAA04` | Device → Accessory | iPhone signals authentication failure | Handled |
| `AuthSucceeded` | `0xAA05` | Device → Accessory | iPhone signals authentication success | Handled |

### 2.2 Identification Plane (`0x1D0x`)
| Message ID | Hex | Direction | Description | Implemented In |
|---|---|---|---|---|
| `StartIdentification` | `0x1D00` | Device → Accessory | iPhone triggers accessory identification | Handled |
| `IdentifyInformation` | `0x1D01` | Accessory → Device | Comprehensive accessory capability declarations | `BuildIdentifyInfo` |
| `IdentifyAccepted` | `0x1D02` | Device → Accessory | iPhone confirms identification parameters accepted | Handled |
| `IdentifyRejected` | `0x1D03` | Device → Accessory | iPhone rejects identification (returns rejected PIDs) | `ParseRejectedParamIds` |

### 2.3 CarPlay Session Plane (`0x430x`)

| `WiredCarPlayAvailability` | `0x4302` | Device → Accessory | Wired CarPlay availability | Constant declared |

## 3. Parameter ID Specifications

### 3.1 IdentificationInformation (`0x1D01`)
* `0`: `Name` (UTF-8 string)
* `1`: `ModelIdentifier` (UTF-8 string)
* `2`: `Manufacturer` (UTF-8 string)
* `3`: `SerialNumber` (UTF-8 string)
* `4`: `FirmwareVersion` (UTF-8 string)
* `5`: `HardwareVersion` (UTF-8 string)
* `6`: `MessagesSentByAccessory` (Packed array of BE16 message IDs)
* `7`: `MessagesReceivedFromDevice` (Packed array of BE16 message IDs)
* `8`: `PowerProvidingCapability` (u8 scalar, `2 = Advanced`)
* `9`: `MaxCurrentDrawnFromDevice` (BE16 scalar, in mA)
* `12`: `CurrentLanguage` (UTF-8 string, e.g. `"en"`)
* `13`: `SupportedLanguage` (UTF-8 string)
* `16`: `USBHostTransportComponent` (Group TLV)
* `17`: `BluetoothTransportComponent` (Group TLV: `0=ID`, `1=Name`, `2=iAP2Support`, `3=MAC`)
* `20`: `VehicleInformationComponent` (Group TLV: `0=ID`, `1=Name`, `2=EngineType`, `6=DisplayName`)
* `24`: `WirelessCarPlayTransportComponent` (Group TLV: `0=ID`, `1=Name`, `2=iAP2Support`, `4=CarPlaySupport`)

### 3.2 NowPlayingUpdate (`0x5001`) Delta Stream
* `0`: `MediaItemTitle` (UTF-8 string)
* `1`: `MediaItemPlaybackDurationInMilliseconds` (BE32)
* `2`: `MediaItemAlbumTitle` (UTF-8 string)
* `3`: `MediaItemArtist` (UTF-8 string)
* `4`: `MediaItemGenre` (UTF-8 string)
* `5`: `MediaItemComposer` (UTF-8 string)
* `6`: `MediaItemTrackNumber` (BE16)
* `7`: `MediaItemTrackCount` (BE16)
* `8`: `PlaybackElapsedTimeInMilliseconds` (BE32)
* `9`: `PlaybackStatus` (u8 enum: `0=Stopped`, `1=Playing`, `2=Paused`, `3=SeekForward`, `4=SeekBackward`)
* `16`: `PlaybackAppName` (UTF-8 string)
* `17`: `PlaybackAppBundleId` (UTF-8 string)

### 3.3 CallStateUpdate (`0x4155`)
* `0`: `RemoteID` (UTF-8 string, phone number)
* `1`: `DisplayName` (UTF-8 string, contact name)
* `2`: `Status` (u8 enum: `0=Disconnected`, `1=Sending/Dialing`, `2=Incoming/Ringing`, `3=Active/Connected`, `4=Holding`, `5=Disconnecting`)
* `3`: `Direction` (u8 enum: `1=Incoming`, `2=Outgoing`)
* `4`: `CallUUID` (UTF-8 string, unique identifier)
* `6`: `AddressBookID` (UTF-8 string)
* `7`: `Label` (UTF-8 string)
* `8`: `Service` (u8 enum: `0=Telephony`, `1=FaceTime`, `2=Cellular`)
* `9`: `IsConferenced` (bool / u8)
* `10`: `ConferenceGroup` (u8)
* `11`: `DisconnectReason` (u8 enum)
* `12`: `StartTimestamp` (BE64 uint)

### 3.4 AcceptCall (`0x415B`) & EndCall (`0x415C`)
* **AcceptCall (`0x415B`)**:
  * `0`: `AcceptAction` (u8 enum: `0=Accept / HoldAndAccept`, `1=EndAndAccept`)
  * `1`: `CallUUID` (optional UTF-8 string)
* **EndCall (`0x415C`)**:
  * `0`: `EndAction` (u8 enum: `0=End / Decline`, `1=EndAll`)
  * `1`: `CallUUID` (optional UTF-8 string)
